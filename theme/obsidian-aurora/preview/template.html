Engineering

Built for this panel

Four decisions that are specific to the S23 Ultra's display, and the reason the gradients stay clean where most dark wallpapers fall apart.

Light accumulates in linear space

Glow blended in gamma space goes chalky and grey. Every ribbon is summed in linear light and tone-mapped once at the end, so the cores roll into white the way real emitted light does.

Dithered against banding

Dark gradients contour badly at 8 bits — you get visible rings. Each render gets triangular-PDF dither at ±0.5 LSB before quantisation, which trades the rings for noise far below the visible floor.

True black is free

On AMOLED an unlit pixel draws nothing, so the base sits at #07080B and the Always-On variant is pure black with a single filament. It lights under a tenth of the screen.

Composition follows the UI

Each variant is composed around what sits on it: a dark ceiling above the lock clock, a sharp lower edge that keeps the shortcut row clean, and a dimmer curtain under the icon grid.

Install

Setting it up

Nothing here needs root and nothing touches system files — it all runs through Samsung's own customisation tools. The first four steps get you most of the way.

  1. Switch the panel to WQHD+
    Display → Screen resolution → WQHD+. The wallpapers are cut for exactly 1440 × 3088.
  2. Set the wallpapers
    Wallpaper and style → Gallery. Turn Wallpaper services off first, and decline the crop — the files already fit.
  3. Turn off the lock-screen dim
    The gradient is already doing that work; One UI's dim just muddies it.
  4. Paste the palette into Theme Park
    Good Lock → Theme Park → Create theme. Override the nine slots above and set it to dark-only, then reboot.
  5. Rebuild the widgets in KWGT
    widgets/placement.json carries every font, size, colour and binding, with coordinates in both pixels and resolution-independent fractions.
  6. Tune the rest with Good Lock
    LockStar for the lock screen, ClockFace for Always-On, QuickStar for the quick panel, Home Up for the grid.
